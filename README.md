# Japan Trip 2026 — Content Source Files

This folder is the content source for a microsite (to be built in Copilot/VSCode)
covering the Feb 2026 Japan trip: destinations, recommendations, and itinerary.


## How this was built

Each destination file follows the same shape:
- **Overview** — what the stop is for, how many days
- **Recommendations** — options by theme (food, culture, nature, pop culture, etc.),
  matched to stated interests: vegetarian-friendly food, mix of street food/sit-down,
  anime/gaming/pop culture, art & design, nightlife/bars, traditional/historic sites,
  fine with iconic spots in small doses
- **Open questions / to research** — anything not yet nailed down

Destinations are filled in as research happens conversation-by-conversation. Files
still marked "not yet researched" are placeholders — check back after each
destination gets its turn.

## Trip constants (for reference across all destination files)

- 16 days total, Fri departure (US) → Sun return (US)
- Traveling with a friend; her portion overlaps for: Tokyo (first 3 days),
  Nagoya/Ghibli Park, Hiroshima, Matsuyama, Beppu/Yufuin, Fukuoka
- Friend snowboards solo in Hokkaido in between (~5-6 days), timed near the
  Sapporo Snow Festival (Feb 4-11)
- Vegetarian, with some non-vegetarian travel companions
- Tattoo-friendly, private-bath lodging needed for the Beppu/Yufuin leg
